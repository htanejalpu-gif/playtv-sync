# PlayTV 24/7 Cloud Stream Sync Engine

Automated GitHub Actions workflow to synchronize live Akamai CDN stream tokens for PlayTV (Sony SAB HD, Sony MAX HD, Sony MAX 2, Sony YAY, Sony Sports Ten 1/2) directly into Firebase Realtime Database Over-The-Air (OTA).

- Runs automatically every 20 minutes via GitHub Actions.
- Zero local maintenance required. 100% cloud-hosted.
